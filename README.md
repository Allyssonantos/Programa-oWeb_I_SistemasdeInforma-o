## Como executar

Como o projeto atual utiliza apenas HTML, não é necessário instalar dependências. Para visualizar a atividade:

1. Acesse a pasta [`Aula_20-08/`](Aula_20-08/).
2. Abra o arquivo [`index.html`](Aula_20-08/index.html) em um navegador.

Também é possível iniciar um servidor local simples na raiz do repositório:

```bash
python3 -m http.server 8000
```

Em seguida, abra <http://localhost:8000/Aula_20-08/> no navegador.
